# Amigo Secreto

Este projeto é uma aplicação simples de sorteio de amigo secreto feita com HTML, CSS e JavaScript.

## Funcionalidades
- Adicionar nomes à lista de participantes.
- Visualizar a lista de amigos adicionados.
- Sortear um amigo aleatório entre os participantes.

## Como Usar
1. Digite um nome no campo de entrada.
2. Clique no botão "Adicionar" para inserir o nome na lista.
3. Quando todos os participantes estiverem adicionados, clique em "Sortear" para escolher um nome aleatoriamente.
4. O nome sorteado será exibido na tela.

## Tecnologias Utilizadas
- **HTML**: Estrutura da página.
- **CSS**: Estilização (se aplicada).
- **JavaScript**: Lógica de manipulação do DOM e sorteio aleatório.

## Como Executar
Basta abrir o arquivo HTML em um navegador para utilizar a aplicação.
